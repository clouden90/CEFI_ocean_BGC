# COBALT GPU-port b2b reference (Case A: OM4.single_column.COBALT, 4×4×75)

The committed reference for the per-section b2b gate (see [../GPU_PORTING.md](../GPU_PORTING.md)).
Generated by the **no-MPI CPU build** (`nvhpc-x86-cpu-nompi`, same source as the GPU build,
`generic_COBALT.o` compiled CPU-only), single-PE, **48 hr @ DT=900** (`input.nml_48hr`, 2 diurnal cycles).

- `ocean.stats.48hr.cpu` — the 48 hr CPU reference ocean.stats (En / SL / S / T per step).
- `roundoff_band.txt` — 10-member round-off ensemble (`KD·(1+k·1e-13)`); the natural noise floor.

**b2b PASS criterion:** a GPU run's final COBALT tracer totals must fall within **~1e-15 relative**
of the CPU reference (the round-off band) — i.e. agree to ~15–16 sig figs. Reference totals:
`dic 1.5036917227507502e13 · alk 1.6266596681460596e13 · no3 1.1316286936109605e11 ·
po4 7.5339372143624897e9 · o2 1.6808066162606292e12`.

(The binary restart `MOM.res.nc` is not committed — text totals + ocean.stats are the criterion;
add the restart here if field-level per-gridpoint b2b is later required. `/scratch5` auto-purges,
so this committed copy is the durable reference.)
