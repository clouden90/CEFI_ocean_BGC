# COBALT GPU-port b2b reference (Case A: OM4.single_column.COBALT, 4×4×75)

The committed reference for the per-section b2b correctness gate (see [../GPU_PORTING.md](../GPU_PORTING.md)).
Generated by the **no-MPI CPU build** (`nvhpc-x86-cpu-nompi`, same source as the GPU build,
`generic_COBALT.o` compiled CPU-only — verified **0 GPU / 0 OpenMP** at source + makefile + build-log +
binary level), single-PE, **48 hr @ DT=900** (`input.nml_48hr`, 2 diurnal cycles), at the model
**default production config `KD = 1.5e-5`** (from `MOM_input`, no override).

- `ocean.stats.48hr.cpu` — the 48 hr CPU reference ocean.stats (En / SL / S / T per step).
- `roundoff_band.txt` — 11-member round-off ensemble (`KD·(1+k·1e-13)` about the default KD); the natural noise floor.

**Reference tracer totals (k=0, unperturbed = production config):**
`dic 1.5036917557803020e13 · alk 1.6266596567821816e13 · no3 1.1316293002204030e11 ·
po4 7.5339387331740561e9 · o2 1.6808058953017490e12`.

**Round-off band (noise floor):** dic 7.8e-16 · alk 4.8e-16 · no3 8.1e-16 · po4 5.1e-16 · o2 4.4e-16 → **~1e-15**.

**b2b PASS criterion:** a GPU run's final COBALT tracer totals must fall within ~1e-15 relative of this
reference (≈15–16 sig figs), *or* a difference proven to be transcendental round-off (cuobjdump + this band).
